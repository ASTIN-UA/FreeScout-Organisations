# OrgPortal — Organization Portal for FreeScout

Модуль для FreeScout, що додає поняття **Організації** (компанії/команди) до клієнтів, розширює End-User Portal для менеджерів і відображає плашку організації на тікетах та картках Kanban.

**Мінімальна версія FreeScout:** 1.8.147  
**Залежності:** немає обов'язкових  
**Опціональні:** [End-User Portal](https://freescout.net/module/end-user-portal/), [API and Webhooks](https://freescout.net/module/api-webhooks/), [Kanban](https://freescout.net/module/kanban/)

---

## Можливості

### Управління організаціями (адмін)

**Manage → Organizations**

- Повний CRUD: створення, редагування назви, видалення організацій
- Таблиця учасників з відображенням email під іменем
- **Зміна ролі** учасника прямо в таблиці через inline-select (без видалення та повторного додавання)
- Додавання учасників через автодоповнення за іменем або email
  - Вже доданих до будь-якої організації клієнтів виключено з результатів пошуку
  - У dropdown відображається ім'я та email знайденого клієнта
- Один клієнт — одна організація (обмеження унікальності на рівні БД)

### Картка клієнта

- Поле **Organization** у стандартній формі редагування клієнта FreeScout
- Вибір організації та ролі (`Member` / `Manager`) через dropdown
- Кнопка **Заявки організації** — відкриває пошук по всіх тікетах організації; динамічно оновлюється при зміні вибраної організації

### Плашка організації на тікетах

- Відображається під тегами на сторінці тікета та в списку розмов
- Розміром і стилем відповідає Bootstrap-тегам FreeScout (`font-size: 75%`)
- Клікабельна — відкриває пошук по всіх тікетах організації
- Увімкнення/вимкнення: **Manage → OrgPortal Settings**

### Плашка організації на картках Kanban

- Відображається під темою тікета на кожній картці
- Клікабельна — веде до пошуку по організації
- Увімкнення/вимкнення: **Manage → OrgPortal Settings**

### Фільтр Kanban по організації

- Пункт **Організація** вбудований у стандартний dropdown фільтрів Kanban (поряд зі Статус, Призначений, Тег тощо)
- Відкриває модальне вікно з чекбоксами по кожній організації та кнопкою «Apply Filter» — аналогічно до вбудованих фільтрів Kanban
- Фільтрація карток відбувається на клієнті (без перезавантаження сторінки)
- Вибір зберігається в `sessionStorage` і застосовується після AJAX-оновлення дошки

### Фільтр пошуку по організації

- Розширює стандартний пошук FreeScout фільтром **Organization**
- Показує тікети всіх клієнтів вибраної організації

### End-User Portal — доступ менеджерів *(опціонально)*

> Активується автоматично при наявності модуля End-User Portal.

**Навігація порталу** (тільки для менеджерів):
- **Тікети компанії** — перегляд всіх заявок членів організації
- **Org Settings** — налаштування email-сповіщень

**Сторінка «Тікети компанії»:**
- Пошук за темою заявки
- Фільтри за статусами Kanban (якщо встановлено Kanban)
- Колонка **Автор** — ім'я клієнта, що подав заявку
- Клік на автора фільтрує заявки лише цього учасника в межах організації
- Посилання на заявку веде до портальної сторінки перегляду тікета з можливістю відповіді

**Фільтри:** модуль використовує `@includeFirst` — якщо EUP-інсталяція надає власний partial `enduserportal::partials.tickets_filters`, він буде використаний автоматично; інакше застосовується вбудований fallback.

**Відповідь на тікети:**
- Менеджер може відповідати на заявки членів організації через портал

**Зміна автора тікета:**
- На сторінці перегляду тікета менеджер може змінити автора заявки на будь-якого іншого учасника організації
- Вибір обмежений лише членами тієї ж організації

### Email-сповіщення

- Менеджери з увімкненою опцією отримують email при створенні нового тікета будь-яким членом організації
- Вимикається на сторінці **Org Settings** порталу
- Використовує поштовий драйвер відповідного mailbox

### REST API *(опціонально)*

> Вимагає модуль [API and Webhooks](https://freescout.net/module/api-webhooks/)

| Метод | Endpoint | Опис |
|-------|----------|-------|
| `GET` | `/api/organizations` | Список організацій (пагінація) |
| `POST` | `/api/organizations` | Створити організацію |
| `GET` | `/api/organizations/{id}` | Отримати організацію |
| `PUT` | `/api/organizations/{id}` | Оновити організацію |
| `DELETE` | `/api/organizations/{id}` | Видалити організацію |
| `GET` | `/api/customers/{id}/organization` | Організація клієнта |
| `PUT` | `/api/customers/{id}/organization` | Встановити організацію клієнту |
| `DELETE` | `/api/customers/{id}/organization` | Видалити клієнта з організації |

Формат відповіді — HAL-подібний: `_embedded`, `page`, `errorCode`.

## Встановлення

1. Скопіюйте папку `OrgPortal` у `Modules/` вашого FreeScout
2. У адмін-панелі: **Manage → Modules → OrgPortal → Activate**
3. Запустіть міграції:
   ```bash
   php artisan module:migrate OrgPortal
   ```
4. Очистіть кеш:
   ```bash
   php artisan cache:clear && php artisan config:clear
   ```

Модуль не має обов'язкових залежностей і встановлюється на будь-який FreeScout. Функції End-User Portal, Kanban та API активуються автоматично при наявності відповідних модулів.

### `organization_members`
| Поле | Тип | Опис |
|------|-----|-------|
| `id` | bigint PK | |

## Налаштування

**Manage → OrgPortal Settings**

| Опція | За замовчуванням | Опис |
|-------|-----------------|-------|
| Show badge on ticket page | ✅ | Плашка організації на сторінці тікета та в списку розмов |
| Show badge on Kanban cards | ✅ | Плашка організації на картках Kanban + фільтр по організації |

Налаштування зберігаються у таблиці `options` FreeScout.
